# Quick Start: Installing Consciousness_Env with Homebrew

## Install

```bash
# Add the tap
brew tap DarkWinD90/Consciousness_Env https://github.com/DarkWinD90/Consciousness_Env

# Install from HEAD (latest development version)
brew install --HEAD consciousness-env
```

## Verify Installation

```bash
consciousness version
```

Expected output:
```
Consciousness System Environment v1.0.0
Multi-Layer Architecture for Synthetic Proto-Consciousness
```

## Basic Usage

```bash
# Run full system integration (Phase 7)
consciousness run

# Run specific phase
consciousness run --phase 1

# Run appendix simulations
consciousness appendix a
consciousness appendix graph
consciousness appendix reflection
```

## Get Help

```bash
# General help
consciousness --help

# Help for specific commands
consciousness run --help
consciousness appendix --help
```

## Update

```bash
brew update
brew reinstall --HEAD consciousness-env
```

## Uninstall

```bash
brew uninstall consciousness-env
brew untap DarkWinD90/Consciousness_Env
```

FIG. 5 — Activity-Dependent Energy Dynamics

This figure shows a graph derived from BalancedEnergyConfig parameters
(core/energy.py) illustrating the energy harvesting and consumption curves
as functions of neural spike count.

X-axis: "Neural Activity (Spikes / Step)" ranging from 0 to 50
Y-axis: "Energy per Step (mWh)"

Two curves:

1. Harvest curve (ref 500, dashed line): Nearly linear, gently increasing
   - Formula: Harvest = 0.20 + (0.09 x spikes) mWh/step
   - Composed of thermal baseline (0.20 mWh at delta_T = 5 degrees C) plus
     piezoelectric harvest proportional to spike-driven motor activity
   - Rises from 0.20 mWh at 0 spikes to approximately 4.7 mWh at 50 spikes

2. Cost curve (ref 502, solid line): Quadratic, starting near harvest level
   - Formula: Cost = 0.225 + (0.006 x s) + (0.0003 x s squared) mWh/step
   - Composed of base consumption (45 mW x 0.005 h = 0.225 mWh) plus
     linear activity cost (1.2 mW x 0.005 h = 0.006 mWh/spike) plus
     quadratic burst penalty (0.06 x 0.005 = 0.0003 mWh/spike squared)
   - Rises from 0.225 mWh at 0 spikes to approximately 1.3 mWh at 50 spikes

Crossover point (ref 506): Harvest equals Cost at approximately 0.3 spikes.
Below this point (0 to 0.3 spikes), cost exceeds harvest (quiescent drain).
Above this point (0.3 to 50+ spikes), harvest exceeds cost (net positive).

Shaded region (ref 504, hatched): Area between curves where harvest exceeds
cost, labeled "NET POSITIVE REGION" with sublabel "Harvest >> Cost
(Self-Sustaining)."

Formula annotation box (ref 508): Contains exact formulas for both curves.

Zone annotation at bottom: "Zone 1: Quiescent Drain — 0-1 Spikes: Cost > Harvest"

Zero reference line: Horizontal dotted line at y = 0.

FIG. 8 — Energy-Bounded Recursive Control Architecture

This figure is the canonical embodiment and reference signal flow for the
entire system. It shows the complete architecture as a vertically stacked
block diagram with bidirectional control paths and energy feedback. This is
the primary reference figure for patent examination.

System operation is constrained by real-time energy availability derived from
physical interaction with the environment, thereby ensuring bounded,
non-abstract execution.


Layout — Vertically stacked functional blocks with lateral connections:


TOP — Physical Environment:
    The physical environment sits at the top of the diagram.

    Two downward arrows from the physical environment:
    Left arrow: "(Light / Temp / Force)" — to Sensor Interface 802
    Right arrow: "(Mechanical Load)" — to Energy Harvesting 804


TIER 1 — Dual Input (left and right, same level):

    Left block:
    Sensor Interface 802 receives environmental signals (light, temperature,
    force) through specific sensor ICs: BH1750 for light, DS18B20 for
    temperature, and piezo input for force.
    Arrow down from Sensor Interface 802 to Neuromorphic Core 806.

    Right block:
    Energy Harvesting 804 performs physical energy transduction: piezoelectric
    element through full-bridge rectifier to supercapacitor storage.
    Arrow down from Energy Harvesting 804 to Neuromorphic Core 806.


TIER 2 — Central Processing (full width):
    Neuromorphic Core (SNN) 806 occupies the full width of the diagram. It
    contains four labeled subsystems:
    - "Spiking Neurons" — leaky integrate-and-fire neural population
    - "Membrane Dynamics" — V(t) = V(t-1) x leak + I_adjusted
    - "Optional STDP" — spike-timing dependent plasticity (opt-in)
    - "Activity-Dependent Energy Cost" — quadratic: base + k x (spikes/N)^2

    Two downward arrows from Neuromorphic Core 806:
    Left arrow: to Recursive Reflection 808
    Right arrow: to Energy Governor 810


TIER 3 — Dual Processing (left and right, same level, BIDIRECTIONAL):

    Left block:
    Recursive Reflection 808 implements the self-observation mechanism. It
    feeds aggregate output at timestep t back as input at timestep t+1, scaled
    by the reflection coefficient. Recursive Reflection 808 maintains prior
    state memory, output feedback, and temporal context.

    Right block:
    Energy Governor 810 enforces energy constraints. It monitors storage
    level, applies the activity-dependent cost function, and damps activity
    when energy is low. Energy Governor 810 manages storage level, cost
    function, and activity damping.

    CRITICAL: Bidirectional arrow between Recursive Reflection 808 and
    Energy Governor 810.
    Label: "Energy state modulates reflection gain; reflection state
    influences energy cost through activity level"

    Both Recursive Reflection 808 and Energy Governor 810 have arrows
    downward to Cognitive Modulation Layer 812.


TIER 4 — Modulation (full width):
    Cognitive Modulation Layer 812 occupies the full width of the diagram. It
    contains four labeled functions:
    - "Attention Weighting" — prioritizes input channels
    - "Intention Bias" — goal-directed modulation
    - "Contextual Suppression / Amplification" — state-dependent gating
    - "(Optional) External Advisory Input" — external control layer when connected

    Two downward arrows from Cognitive Modulation Layer 812:
    Left arrow: to Neural Router 814
    Right arrow: to Telemetry & Logging 816


TIER 5 — Output (left and right, same level):

    Left block:
    Neural Router 814 performs signal arbitration. It routes neural output to
    actuators based on priority, gates signals when energy is insufficient,
    and prevents output saturation through congestion control.
    Arrow down from Neural Router 814 to Actuation & Response 818.

    Right block:
    Telemetry & Logging 816 provides observability output. It records energy
    level, system state, and reflection metrics for validation and monitoring.
    No downward arrow from Telemetry & Logging 816 (terminal output).


TIER 6 — Actuation (full width):
    Actuation & Response 818 occupies the full width of the diagram. It
    contains servo control, mechanical interaction, and environmental
    perturbation subsystems. Actuation & Response 818 drives mechanical
    interaction, which perturbs the environment (closing the loop back to
    the physical environment at top) and generates mechanical load (feeding
    Energy Harvesting 804 at Tier 1).

    Two upward feedback arrows from Actuation & Response 818:
    1. Arrow back to the physical environment (top): "Environmental Perturbation"
    2. Arrow back to Energy Harvesting 804 (Tier 1 right): "Mechanical Load
       generates piezoelectric energy"


FEEDBACK LOOPS (mark each distinctly):

    Loop A — Energy Harvesting Loop:
    Actuation & Response 818 → Mechanical Load → Energy Harvesting 804 →
    Neuromorphic Core 806
    Style: Bold solid arrows
    Label: "ENERGY LOOP — Motor activity generates power for neural computation"

    Loop B — Recursive Reflection Loop:
    Neuromorphic Core 806 → Recursive Reflection 808 → Neuromorphic Core 806
    Style: Dotted arrows
    Label: "REFLECTION LOOP — Prior state observation at configurable gain"

    Loop C — Environmental Perturbation Loop:
    Actuation & Response 818 → Environment → Sensor Interface 802 →
    Neuromorphic Core 806
    Style: Dashed arrows
    Label: "SENSORY LOOP — Actions change environment, environment changes input"

    Loop D — Energy Governor Feedback:
    Energy Harvesting 804 → Energy Governor 810 ↔ Recursive Reflection 808 →
    Cognitive Modulation Layer 812
    Style: Thin solid arrows
    Label: "REGULATION LOOP — Energy availability constrains all processing"


Key annotations at bottom of figure:
